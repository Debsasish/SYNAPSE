01 / benchmark results

Constant interface.
Non-constant advantage.

A flat protocol pays for the entire catalogue every turn. SYNAPSE pays for a bounded interface. The advantage emerges at scale without concealing where the baseline wins.

Fixed surface

Six meta-verbs and an out-of-context resolver keep prompt growth independent of tool count.

Artifact output

Context, cost, hit@k, reliability, ablations, and activation-size sweeps are generated from the repository.

Bounded claim

The catalogue is synthetic, reference ANN is not wall-clock optimal, and no live agent loop is evaluated.

02 / protocol

Three planes.
One bounded interface.

Storage, resolution, and interaction are separate. The model never receives the whole catalogue; it requests structure only when needed.

01

Capability graph

Signed capability, type, provider, and concept nodes allow typed expansion and integrity checks outside prompt context.

02

Hybrid resolver

Semantic, lexical, ontology, graph, and type-fit signals produce a shortlist with calibrated confidence.

03

Six meta-verbs

intend / focus / plan / invoke / observe / feedback form the constant model-facing surface.

03 / Jev baseline

Reranking the shortlist.

If Jev receives a bounded shortlist, can it select the best tool more accurately than SYNAPSE top-1? Not in this experiment—but the result is not a general verdict on Jev.

Observed

  • Resolver top-1 wins at both scales.
  • Larger Jev shortlists perform slightly worse.
  • All arms abstain on all five impossible tasks.

Why

  • Many Jev mistakes are textual look-alikes.
  • Jev lacks graph and type-fit structural signals.

04 / methodology

Trust the artifact.
Read the caveats.

The evidence is reproducible, but its claims are bounded. Limitations remain adjacent to the results—not hidden in fine print.

Core limits

  • Synthetic catalogue, not a production ecosystem.
  • Reference ANN wall-clock grows; the claim concerns prompt context.
  • 90 real tasks plus five impossible tasks.
  • Tag-withheld tasks drive remaining degradation.

Jev limits

  • One seed, two catalogue sizes, one prompt wording.
  • Full-catalog tournament stopped on upstream HTTP 429s.
  • Model alias/version is not pinned.
  • Responses are cached and de-duplicated.
